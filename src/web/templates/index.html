How it works

01

Deterministic diff

Sections are aligned by anchor equality; paragraphs matched via embedding similarity. Every change is classified (unchanged / minor / major / added / removed) before the LLM ever sees it.

02

Verified interpretation

Only changed passages reach the model, and only to explain them. Every quote it returns must be a literal substring of the filing — quotes that fail validation are dropped, never rendered.

03

A report, not a diff

The verified changes are composed into chapters that follow the 10-K's own structure — a 15-minute read, with audited XBRL figures for every year and a citation behind every claim.

Why this matters

The Lazy Prices research (Cohen, Malloy, Nguyen) found that firms whose filings change the most subsequently underperform the market. Analysts don't read diffs. Delta does.

The LLM never finds the diff. It only explains it. Detection is deterministic. Interpretation is generative. Every claim traces to a diff record.
